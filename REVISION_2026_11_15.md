# MIMO simulation — full corrected source (15 November 2026)

This folder is the **full editable MATLAB project**, based on the uploaded `matlab-main (1).zip`. No simulations were run in the packaging environment (MATLAB is not installed).

## Targeted changes

1. `code/mimo_parameters.m`: increase full-run bit cap **16,000,000 → 40,000,000** per SNR/configuration to allow the unresolved 4×6 at +12 dB point to meet the cluster-robust precision target; still an upper cap, not a guarantee. Enforce the existing assumption **Es = 1**.
2. `code/plot_mimo_results.m`: auto-scale each 2D log-BER axis to plotted **positive** values; remove excessive empty space; turn off dense minor grid lines; use six-ish SNR tick marks; change 3D *surface interpolation* to **three `plot3` curves at the measured Nr=4,5,6 only**, with distinct markers/line styles and no simulated points between antenna counts. Preserve existing figure filenames for the report. Rename SINR axis to say explicitly that the averaging is performed in dB.
3. `code/mimo_cluster_se.m`: factor out the existing exact cluster-SE computation so it can be independently tested; the simulation formula is otherwise unchanged.
4. `code/run_self_tests.m`: add a direct cluster-SE check and a deterministic independent-block Monte Carlo ZF benchmark at 0 dB versus analytic Rayleigh BER; regularization/noiseless/SINR and Craig-integral tests remain.
5. `code/validate_mimo_outputs.m`: in addition to binary PDF/PNG verification, check that the saved MAT file has consistent antenna/SNR dimensions and `BER = errors/bits`.
6. `code/run_mimo_project.m`: show an explicit summary of whether all detectors reached the target precision at each tested SNR/configuration.

**Unchanged:** Rayleigh channel, spatial multiplexing BPSK, ZF/MMSE/MRC detector formulas, RNG seed, per-stream SNR definition, existing CSV/MAT format, 11 expected figure stems, 3D PDF raster export and ZIP validation.
